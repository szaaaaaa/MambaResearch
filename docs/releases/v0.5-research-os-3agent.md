# v0.5 - 3-Agent Research OS（首次角色分工）

> **Commit**: `36d41d2` · **日期**: 2026-03-09 · **Tag**: `v0.5-research-os-3agent`

## 版本定位

首次把"**谁做什么**"从隐式节点逻辑抽成**显式角色**的过渡版本——`b5cf8be feat: add 3-agent Research OS orchestrator` 引入 3 角色协作（conductor / researcher / writer），架构上从"LangGraph 图节点"演进为"Research Operating System"概念。

注：此版本在架构叙事上是独立里程碑，但生命周期极短（约 1 天后被 v0.9 六角色版覆盖）。底层仍跑在 LangGraph 之上。

## 主要能力

- **3 角色分工**：conductor（编排）/ researcher（检索 + 索引）/ writer（合成报告）
- **artifact 契约雏形**：`src/agent/artifacts/` 首次引入带 schema 的 artifact 注册表
- **skill 运行时骨架**：`src/agent/skills/` 把节点逻辑拆成独立 skill 单元
- **provider adapters 统一**：LLM 后端（OpenAI / Gemini）走统一 adapter 层
- **role-specific LLM**：每个角色可绑定独立模型（ac11605）
- **前端 control plane**：首次有 web UI 渲染 stage brief（a55dd0d、96939c8）

## 技术栈

- **编排**：LangGraph 状态图 + Research OS orchestrator 包装层
- **artifact 系统**：自建 schema 注册表 + serializers
- **前端**：首版 web 控制台，用于观察执行

## 当时的局限

- 3 角色不足以覆盖科研完整链路（缺实验、分析、审稿）
- orchestrator 和 LangGraph 两套调度并存，职责重叠
- skill / artifact 契约还在草案阶段，没有强类型校验

## 为什么进化到下一版

3 角色覆盖面不够。同一天（2026-03-09）的 `1c999a3` 直接把它扩展为 6 角色，进入 v0.9 **6-Agent Research Operating System**。
