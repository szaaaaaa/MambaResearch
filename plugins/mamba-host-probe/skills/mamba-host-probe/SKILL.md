# MambaResearch 宿主接入验收

这是开发验证插件，尚未替换科研工作台，也不会启动 Codex CLI 或修改研究数据。

调用本插件的 `open_probe` 工具，让宿主展示它关联的 MCP UI。请用户点击面板里的“发送验证任务”。
不要用普通浏览器打开 HTML 来代替 MCP UI 验收；普通页面没有宿主消息桥。
若工具不可用，报告当前聊天未暴露该 MCP；skill 可见不代表 MCP 已发现或启动。
先检查插件配置发现和服务启动，不能只凭工具缺失归因于未重启，也不能声称已验证。

收到面板发来的验证请求后，使用消息中的 `probe_id`、`nonce` 调用 `confirm_probe`，
然后报告工具结果。不要在用户尚未点击面板时提前确认，不要模拟点击。
`read_probe` 可以检查当前记录；超时或只有消息发送成功都不代表模型已执行。

完成后区分四项证据：UI 实际展示、宿主握手、当前聊天出现按钮消息、模型确认结果返回面板。
面板在发送后的 90 秒内定期检查确认状态；结束或发生错误后可点击“检查回传”。
服务端确认并不证明面板已经显示确认结果，也不证明工作台全部业务已迁移。

服务依赖 Python 与 `requirements.txt` 中的 MCP SDK，插件相对路径以插件根目录为基准。
运行记录只在这个验证服务进程内保存；重启后应重新调用 `open_probe` 创建新记录。
